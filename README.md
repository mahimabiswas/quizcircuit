# QuizCircuit

A real-time live quiz platform where nobody needs an account. Questions are generated by AI from your own documents.

Upload your notes and share a join link. Players join with just a name, answer timed questions together, and see a live leaderboard at the end.

## How it works

1. **Upload**: the host uploads documents (notes, slides, readings).
2. **Generate**: QuizCircuit drafts multiple-choice and true/false questions, each citing the passage it came from.
3. **Review**: the host edits or removes questions before the game starts.
4. **Play**: players join by short code or link, wait in a live lobby, and answer questions on a server-controlled timer.
5. **Results**: scores update in real time and a final leaderboard closes the game.
